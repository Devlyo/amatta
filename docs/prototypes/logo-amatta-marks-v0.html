아마따 로고 마크 — round 2

4가지 방향: M1 ㅇㅁㄸ 자모 삼각 (내부 hollow + 붙임) · M2 캘린더 shape (Instagram-style 깔끔) · M3 Musinsa-style 워드마크 (clean, no shadow) · M4 Sparkle 마크 단독.

M1ㅇㅁㄸ — 자모 삼각, 내부 hollow + 붙여서

ㅇ과 ㅁ 내부 hollow 유지 (도넛/프레임 형태). wall 두께 8px 통일. ㅇ ↔ ㅁ/ㄸ 행 사이 거리 4px 좁혀 시각적으로 접하는 느낌 ↑ (이전 I1보다 dense). ㅁ-ㄸ는 x=60 라인에서 접함.

M2Calendar shape — Instagram-style 깔끔한 캘린더

캘린더 → "아 맞다!"의 느낌표가 안에. Instagram 카메라처럼 단순 outline + 가운데 정체성 글리프. 캘린더 = 우리 앱 카테고리 직관 + 느낌표 = "아 맞다!" 순간. 작은 사이즈에서 stroke 두께 자동 가변 (5→6px).

a / e 디벨롭 6종. D1 = a 원본 / D2 = a + 작은 광택점 / D3 = a + 외곽 진한 톤 rim / D4 = e 원본 radial / D5 = e + highlight 광택 / D6 = e+ 4-stop 깊은 gradient + 작은 광택. 모두 110×110(lg) 동일 사이즈.

D4 사이즈 스케일 (xl · lg · sm · xs · xxs)
4 방향 비교. M1 = 추상 자모 (브랜드 의미는 약하지만 절제). M2 = 컨텍스트 (캘린더). M3 = 글자 (정체성 명확). M4 = 감정 (sparkle = 깨달음 순간).
가능 조합. M3 wordmark + M2/M4 icon = 페어. M1은 단독 picto. 다음 단계: 골라주시면 컬러 variant + 페어 사용 가이드.
