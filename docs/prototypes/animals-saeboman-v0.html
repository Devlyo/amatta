스타일. Matisse paper-cutout — flat fill, no gradient, no drop shadow. 모든 동물은 단일 hue + 보조 톤 1~2개로만. 눈 highlight는 cream 작은 점 하나로 paper-cutout 위에 살짝 생기 주는 정도.

색 분산. 토끼=warm beige(+분홍 inner), 판다=흑백, 펭귄=흑백+mustard 부리, 갈색곰=warm brown. 판다·펭귄 모두 흑백이지만 판다=흰 얼굴+흑 귀+흑 패치, 펭귄=흑 정수리+흰 페이스마스크+노란 부리 → 32px에서도 한눈에 구분.

Paper-cut edge. 모든 동물 outer silhouette에 charcoal opacity stroke (rgba(28,28,28,0.22), 1.6px) — 배경 ring(pink/green/blue/yellow) 위에서 종이 잘라 붙인 느낌으로 분리감 확보.

V1.0 매핑. 자녀 4종 고정 — 등록 순서대로 토끼(c1)·판다(c2)·펭귄(c3)·갈색곰(c4). 코알라는 부모 앱 브랜드 마스코트로만 사용 (자녀 후보 ❌). V1.1+에서 자녀별 동물 선택 가능 여부 검토.
