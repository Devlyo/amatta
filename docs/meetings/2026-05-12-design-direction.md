## 결정사항

### 1. 주간뷰 — 보기 토글 추가
- 캘린더 메인 상단, 검색 버튼 옆에 **"보기" 토글** 추가
- 두 모드:
  - **자녀별** (기존) — 자녀 1명 × 7일
  - **합쳐서 보기** (신규) — 자녀 N명 × 7일을 **바 형태**로 한 줄에 표시, 일정 종류는 **카테고리 아이콘**으로 분류
- 친구 트랙의 weekly 합쳐 보기 스타일 참고

### 2. 가장 가까운 픽업시간 — 상단 sub-bar 표시
- **픽업 정의**: 일정의 **종료시간** (별도 픽업 시각 필드 없음)
- 일간뷰 상단 sub-bar에 다음 픽업까지의 정보 표시:
  - 가장 가까운 픽업 시각 (예: `17:30`)
  - 해당 자녀 + 일정명 (예: `서윤 · 미술 종료`)
- 픽업 충돌 sub-bar와는 별개 정보 (충돌은 별도 row)

### 3. 시간 표시 — 12h / 24h 토글
- 설정에서 사용자 토글 (24시간 표기 / 오전·오후 표기)
- 친구 트랙 `settingsStore` 에 이미 존재 — 우리 디자인에 반영 필요

### 4. 개인정보처리방침 / 이용약관 — 작성 확정
- 회의 중 "필요없다"로 잘못 알고 있었음 → 사실 **한국 앱스토어 출시 시 필수**
- 자녀 정보(이름·연령·일정) 수집 = 개인정보처리자 의무 발생
- 14세 미만 자녀 정보 → 법정대리인 동의 필수 (가드레일 기존 항목)
- 목요일 회의에서 초안 논의
