## 화면 매핑

| # | 화면 | 진입 경로 | 메모 |
|---|---|---|---|
| 1 | 온보딩 | 첫 실행 | "welcome to 스케쥴링" — 1회성 |
| 2 | 자녀 등록 | 온보딩 후 / 설정에서 추가 | 이름 + 사진 (사진 의도 TBD) |
| 3 | **일간뷰 (메인)** | GNB의 today | **두 탭**: 일정 / 준비물&할일 |
| 3a | └ 일정 탭 | 디폴트 | 자녀×시간 그리드 + 충돌 sub-bar |
| 3b | └ 준비물&할일 탭 | 탭 전환 | Apple 리마인더 스타일 인라인 추가 (별도 페이지 없음) |
| 4 | 주간뷰 | 메인에서 자녀 이름 클릭 | 자녀 1 × 7일 × 시간. **준비물·픽업 생략, 일정만** |
| 5 | 일정 추가 폼 | FAB(+) | 자녀·제목·시각·반복·알림·준비물·저장 (풀스크린) |
| 6 | 일정 상세 박스 | 일정 블록 클릭 | 작은 오버레이 (큰 시트 아님) |
| **drawer** | 날짜 선택 | 상단 날짜 클릭 | 위에서 내려오는 drawer (월간뷰 아님) |
| **drawer** | 검색 | 상단 검색 클릭 | 입력 시 자녀 결과 리스트 drawer |

## Global Navigation Bar (하단 고정)
세 항목 (왼쪽 → 오른쪽):
1. **Today** — 일간뷰 메인으로
2. **FAB +** — 신규 일정 추가 (중앙, 강조)
3. **설정** — 자녀 관리 + 앱 설정

## 명시적 비포함 (와이어프레임 검토 후 확인)
- 월간뷰 — 없음 (날짜 drawer로 대체)
- 알림 탭 — GNB에 없음 (일정 알림은 OS 푸시로만)
- 자녀 탭 — 별도 탭 없음 (설정 안에)
