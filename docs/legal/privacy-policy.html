WeMoa 개인정보처리방침

시행일: 2026년 11월 12일

WeMoa는 사용자가 안심하고 서비스를 이용하실 수 있도록 본 약관 및 개인정보처리방침을 마련하고 있습니다.

1. 수집하는 정보

운영자는 서비스 제공을 위해 사용자가 직접 입력한 최소한의 정보만 기기 내부에 저장합니다. 별도의 회원가입은 요구하지 않으며, 입력하신 정보는 사용자가 직접 공유하지 않는 한 외부 서버로 전송되지 않습니다.

  • 자녀 정보: 이름, 선택한 테마 색상
  • 일정 정보: 제목, 시간, 장소, 카테고리, 픽업 여부
  • 준비물·할일 정보: 제목, 마감 시점, 완료 여부
  • 앱 설정: 알림 활성화 여부, 기본 알림 시점, 캘린더 연동 여부와 표시할 캘린더
  • 기기 캘린더(캘린더 연동을 켠 경우에만): 보호자 일정을 화면에 함께 보여 주기 위해 기기의 캘린더 일정을 읽고, 앱에서 추가한 보호자 일정을 기기 캘린더에 저장합니다. 캘린더 일정은 앱에 따로 저장되지 않으며 외부로 전송되지 않습니다.

2. 정보의 저장 위치

입력하신 모든 정보는 사용자의 기기 내부 저장소에만 보관됩니다(직접 만든 캘린더 공유 링크의 암호화된 사본은 예외로, 14일 뒤 자동 삭제). 운영자는 사용자의 데이터를 별도 서버에 저장하거나, 제3자에게 전송하지 않습니다.

JSON 백업(내보내기) 기능을 사용하실 경우 백업 파일이 생성되며, 해당 파일을 어디에 보관할지는 사용자가 직접 결정하실 수 있습니다.

3. 캘린더 공유 링크

캘린더 공유 기능을 사용하시면, 사용자가 고른 아이의 오늘부터 1주 일정(이름, 일정 제목·시간, 선택 시 준비물·장소·메모)이 기기에서 암호화된 뒤 공유 서버(Vercel)에 14일 동안 보관되고, 이후 자동으로 삭제됩니다. 암호를 푸는 열쇠는 링크의 “#” 뒷부분에만 들어 있어 서버로 전송되지 않으므로, 운영자와 서버 제공자는 보관된 내용을 볼 수 없습니다. 웹 보기 페이지는 방문 기록·분석 도구를 사용하지 않습니다.

다만 링크는 사용자가 보낸 메신저·메일의 기록, 받는 분의 브라우저 기록 등에 남을 수 있고, 링크를 가진 누구나 14일 동안 내용을 볼 수 있으며 이미 보낸 링크는 취소할 수 없습니다. 믿을 수 있는 분에게만 공유해 주세요.

4. 정보의 이용 목적

수집된 정보는 아래의 목적으로만 사용되며, 명시한 범위를 벗어나는 용도로는 이용되지 않습니다.

  • 일간뷰·주간뷰 화면 구성 및 자녀별 색상 표시
  • 예정된 일정 및 픽업에 대한 사전 알림 발송(기기 내 로컬 알림)
  • 준비물·할일의 완료 상태 추적
  • 사용자 본인이 요청하신 데이터 백업(JSON 내보내기)
  • 사용자 본인이 요청하신 보기 전용 캘린더 공유 링크 생성

5. 정보의 보관 기간

사용자가 직접 항목을 삭제하시거나 “모든 데이터 초기화” 기능을 사용하시기 전까지 정보는 기기 내부에 보관됩니다. 앱을 삭제하실 경우 모든 데이터는 즉시 함께 제거되며, 운영자는 별도의 사본을 보유하지 않습니다.

6. 제3자 제공

운영자는 사용자의 정보를 어떠한 경우에도 제3자에게 제공하거나 위탁하지 않습니다(사용자가 직접 공유 링크를 보내는 경우는 사용자의 선택입니다). 다만 법령에 따라 수사기관의 적법한 요청이 있는 경우에는 협조할 수 있으며, 이때에도 그 사유와 범위를 가능한 한 사용자에게 안내합니다.

7. 사용자의 권리

사용자는 언제든지 다음의 권리를 행사하실 수 있습니다. 모든 작업은 별도의 신청 없이 앱 내에서 직접 수행 가능합니다.

  • 저장된 정보의 열람 및 수정
  • 특정 항목의 삭제 또는 전체 초기화
  • JSON 백업(내보내기)을 통한 정보의 보관
  • 알림 동의의 철회(설정 또는 기기 알림 권한)
  • 캘린더 접근의 철회(설정 > 캘린더 연동 또는 기기 캘린더 권한)

8. 아동의 개인정보

WeMoa는 자녀의 일정을 관리하는 보호자를 위한 도구로서, 자녀 본인이 직접 사용하는 것을 전제로 설계되지 않았습니다. 보호자가 입력하신 자녀 정보는 보호자의 책임 하에 관리되며, 운영자는 해당 정보를 외부와 공유하지 않습니다. 공유 링크는 보호자가 직접 만들어 보낼 때에만 생성됩니다.

10. 방침의 변경
