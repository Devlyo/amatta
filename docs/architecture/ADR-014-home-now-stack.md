# ADR-014 — 홈 "지금" = 타임블록 스택 + 아이폰 느낌 레이아웃

- **Status**: **Accepted / 구현 완료, 기기 확인 전** (2026-11-11) — 오너 "H1으로 가보자"
- **Source**: 디자인 캔버스(비공개) https://claude.ai/artifact/7378YLCUUr4pMf7SgDfybx — 보드 `H1`(접힘)·`H2`(펼침). `H3`(지갑처럼 겹치기)는 폐기.
- **Supersedes (부분)**: ADR-007 §6-1 "지금·다음" 줄 목록, ADR-007 "기본 박스 RADIUS.box(14)"(홈 카드만 22)

## Decision
1. **지금 = 아이마다 타임블록 1장**(캘린더 블록과 같은 모양: 아이 색 60% + 왼쪽 진한 줄 3px). 블록 안: 아바타 · 이름 · 제목 · 시간 범위 · 상태 알약.
   - 진행 중: "진행 중 · N분 남음" + 진행 막대 + "다음 4:30PM 수영"
   - 시작 전: "40분 후"
   - 오늘 남은 일정 없음 / 일정 끝: 흰 카드에 회색 글자
2. **접힘(기본)**: 가장 급한 블록이 맨 위(진행 중 → 끝나는 시간 순, 그다음 시작 전 → 시작 시간 순, 그다음 일정 없는 아이). 나머지는 아래로 최대 2장 살짝 보인다(아이폰 알림 스택). 탭하면 펼쳐지고, 맨 아래 "접기". 아이가 1명이면 블록 1장만.
3. **아이폰 느낌**: 날짜 캡션 위 + 큰 제목 "오늘"(34), 오른쪽에 아이 얼굴 겹침. 칸 제목 = Title2(22/700) + 옆에 개수, "캘린더 ›"는 주황. 홈 카드 radius `RADIUS.card`(22). 칸 사이 간격 26.
4. **준비물·할 일 = 아이폰 목록**(보드 H1): 한 줄에 하나씩, 줄 사이 얇은 선(글자 시작 위치부터).
   - 준비물: 아이 얼굴 · 준비물 이름 · "민준 · 수학 2PM" · 오른쪽 동그라미 체크(완료 = 주황). 일정별 머리줄은 없앰.
   - 할 일: 왼쪽 동그라미 체크 · 제목 · (아이가 정해져 있으면) 아이 이름.
5. **홈 바탕 = `homeBg` #F7F6F4**(시스템 화면 `groupedBg` #F2F1EF보다 연하게, 오너 2026-11-11). 다크는 그대로.
6. 새 토큰: `RADIUS.card`, `TYPE.title2`·`largeTitle34`, `surfaceOnFill`·`surfaceOnFillMuted`(색 위의 알약·막대, 두 모드 같음), `homeBg`.
