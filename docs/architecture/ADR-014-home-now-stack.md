# ADR-014 — 홈 "지금" = 타임블록 스택 + 아이폰 느낌 레이아웃

- **Status**: **Accepted / 구현 완료, 기기 확인 전** (2026-11-11) — 오너 "H1으로 가보자"
- **Source**: 디자인 캔버스(비공개) https://claude.ai/artifact/7378YLCUUr4pMf7SgDfybx — 보드 `H1`(접힘)·`H2`(펼침). `H3`(지갑처럼 겹치기)는 폐기.
- **Supersedes (부분)**: ADR-007 §6-1 "지금·다음" 줄 목록, ADR-007 "기본 박스 RADIUS.box(14)"(홈 카드만 22)

## Decision
1. **지금 = 아이마다 타임블록 1장**(캘린더 블록과 같은 모양: 아이 색 45% + 왼쪽 진한 줄 3px). 블록 안: 아바타 · 이름 · 제목 · 시간 범위 · 상태 알약.
   - 진행 중: "진행 중"(남은 시간 글자 없음, 오너 2026-11-11) + 진행 막대 + "다음 4:30PM 수영"
   - 시작 전: "40분 후"
   - 오늘 남은 일정 없음 / 일정 끝: 흰 카드에 회색 글자
2. **진행 중 = 항상 펼침**(오너 2026-11-11): 진행 중인 아이 카드는 모두 펼쳐 둔다. 쌓는 건 그 아래 나머지(시작 전·일정 없음)만, 2장 이상일 때. 쌓인 카드는 맨 위 카드 높이로 그려서 더 큰 카드가 위로 튀어나오지 않음. 가시성(2026-11-11): 뒤 카드는 투명도 **94%/88%**(85/70%는 바탕에 묻힘)로 한 단계씩 연하게, 아래로 **11pt/22pt** 보이고 모서리 18/16pt, 쌓인 카드마다 사방으로 옅은 그림자(`ELEVATION.stack`, 오프셋 0·반경 8·12%, 펼치면 사라짐).
   **접힘(기본)**: 가장 급한 블록이 맨 위(진행 중 → 끝나는 시간 순, 그다음 시작 전 → 시작 시간 순, 그다음 일정 없는 아이). 나머지는 아래로 최대 2장 살짝 보인다(아이폰 알림 스택). 탭하면 펼쳐지고, 맨 아래 "접기". 아이가 1명이면 블록 1장만.
3. **아이폰 느낌**: 날짜 캡션 위 + 큰 제목 "오늘"(34), 오른쪽에 아이 얼굴 겹침. 칸 제목 = Title2(22/700) + 옆에 개수, "캘린더 ›"는 주황. 홈 카드 radius `RADIUS.card`(22). 칸 사이 간격 26.
4. **준비물·할 일 = 아이폰 목록**(보드 H1): 한 줄에 하나씩, 줄 사이 얇은 선(글자 시작 위치부터).
   - 준비물: 아이 얼굴 · 준비물 이름 · "민준 · 수학 2PM" · 오른쪽 동그라미 체크(완료 = 주황). 일정별 머리줄은 없앰.
   - 할 일: 왼쪽 동그라미 체크 · 제목 · (아이가 정해져 있으면) 아이 이름.
5. **카드 배경을 연하게**(오너 2026-11-11 "카드 배경"): 지금 카드 = 아이 색 **45%**(다크 70%, `theme.cardFill`). **캘린더 타임 블록도 같은 농도**(`blockFill` 60→45%, 강조 80→65%; 다크 85→70%, 강조 95→85%) — 일·주·월 블록·막대·하루 종일 칩 모두. (ADR-007 "자녀 색 60%"를 대체) 홈 바탕은 `groupedBg` 그대로.
6. **픽업 카드**(보드 H1): "다음 픽업 · 40분 남음" + 큰 "3PM 민준 · 수학"(20/700) + 오른쪽 **완료** 알약(누르면 그 회차 픽업 완료 → 카드가 사라짐). 자동차 그림·길 줄은 뺌. 색은 기존 픽업 팔레트, radius 22.
7. **블러 독**: `expo-blur` BlurView(systemChromeMaterial) + `dockTint` 55%. 모듈이 없는 예전 빌드에서는 흰 알약 그대로(lazy).
8. 새 토큰: `RADIUS.card`, `TYPE.title2`·`largeTitle34`, `surfaceOnFill`·`surfaceOnFillMuted`(색 위의 알약·막대, 두 모드 같음), `dockTint`; Theme `cardFill`.

9. **다크 모드 왼쪽 막대**(2026-11-11): 다크에서는 블록 채움이 밝아서(70%) 다크용 밝은 `deep`이 묻혔다 → 채움 위 막대 전용 `KidPalette.bar`(라이트 = `deep`, 다크 = 진한 색, 채움 대비 약 3:1 이상). 일·주 블록·주간 막대·하루 종일·지금 카드 막대와 진행 막대에 사용. 다크 막대 두께 1.5 → 2.5pt.

## Consequences
- `expo-blur` = 새 네이티브 모듈 → 개발 빌드 새로 필요(2026-11-11 빌드).
