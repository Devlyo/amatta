# ADR-016 — 캘린더 링크 공유 (보기 전용, 서버 저장 없음)

- **Status**: **Accepted / 구현 완료, 배포 전** (2026-11-12) — Architect·Critic 리뷰 반영(아래 *Review*) — 오너 "다른 보호자에게 캘린더 화면을 링크로, 수정 불가·일정 정보·주간 뷰까지" → 방식 **A**(데이터는 링크 안에만), 호스팅 **Vercel**, 기본값 = 4주 · 준비물 포함 · 장소·메모 빼기
- **Source**: 디자인 캔버스(비공개) https://claude.ai/artifact/7378YLCUUr4pMf7SgDfybx — 보드 `SH1`–`SH4`. 계획: `.omc/plans/ralplan-share-link.md`
- **Relates**: ADR-001 "온라인 기능 없음"을 **부분 완화** — 앱은 여전히 서버·계정·동기화가 없다. 새로 생기는 건 *정적* 웹 보기 페이지 하나뿐이며, 일정 데이터는 그 서버에 전송·저장되지 않는다.

## Decision
1. **링크 = `https://<host>/s#<payload>`**. payload는 링크의 `#` 뒤(fragment)에만 있다 → 브라우저가 서버로 보내지 않음. 웹 페이지는 받은 fragment를 브라우저 안에서 풀어서 그린다.
2. **payload** = 공유 시점에 앱이 **미리 펼친 회차 목록**(앱과 같은 규칙: 반복·예외·함께하는 일정·준비물 회차 규칙이 그대로 반영됨) + 아이 목록(이름·색·아바타) + 메타(만든 날짜·기간). JSON → `lz-string` `compressToEncodedURIComponent`, 링크 = `#<버전>.<압축>`(버전이 압축 밖이라 옛 보기 페이지도 "새 버전" 안내 가능). 16K자 넘는 링크·형식이 맞지 않는 값은 거절.
   - 담는 것: 날짜, 시작·끝(하루 종일), 제목, 종류, 함께하는 사람(보호자 포함 여부), 반복 요약 문구, 픽업 여부·시각, (선택) 그 회차 준비물, (선택) 장소·메모.
   - 담지 않는 것: 아이폰 캘린더의 보호자 일정(기기 데이터), 할 일, 완료 기록, 알림 설정.
3. **앱 화면(SH1)**: 캘린더 상단 공유 버튼 → "캘린더 공유" 시트: 보여 줄 아이(기본 전원) · 기간 2/4/8주(기본 4) · 준비물 포함(기본 켬) · 장소·메모 포함(기본 끔) · 개인정보 안내 → "링크 공유하기" = iOS 공유 시트.
4. **웹 보기(SH2–SH4)**: WeMoa 모양 주간 보기(4일/7일 너비 전환), 주 넘기기(담긴 기간 안), 아이 필터 알약, 일정 누르면 상세 시트(수정 불가 안내). 상단 "보기 전용 · 11월 12일 기준". 기간이 끝났거나 7일 넘게 지난 링크는 안내 띠. 깨진·새 버전 링크는 안내 화면.
5. **호스팅**: Vercel 정적 배포(`web/share/public/`, 빌드 = `npm run share:build`, esbuild로 `src/share/share-codec.ts`를 그대로 묶음 — 앱과 웹이 같은 코드). **외부 요청 0**(CDN·웹폰트·분석 없음, 시스템 글꼴), 엄격한 CSP·`no-referrer`·`noindex`. Vercel Analytics·Speed Insights 끔. 앱 상수 `SHARE_BASE_URL`.
6. **크기**: 4주·아이 4명 기준 목표 < 4KB(URL). 넘치면 기간을 줄이라고 안내.

## Consequences
- 링크를 가진 사람은 누구나 볼 수 있다(취소 불가). 공유 화면에 안내.
- 개인정보 처리방침(legal 화면)에 "공유 링크" 항목 추가 필요.
- 웹 주소가 바뀌면 이미 보낸 링크는 깨진다 → 도메인을 정하면 고정.

## Review (ralplan, 2026-11-12) — 반영 사항
- 고르지 않은 아이는 함께하는 일정의 멤버 목록에서도 빠짐(색·이름도 고른 아이 기준).
- 개인정보 문구: "외부로 전송되지 않음" → "사용자가 직접 공유하지 않는 한", 공유 링크 절 추가(메신저·브라우저 기록에 남을 수 있음, 취소 불가). 공유 화면에도 같은 안내.
- 웹: 링크의 글자는 모두 `textContent`(HTML로 해석 안 함), 인덱스·종류·아바타 값 범위 검사.
- 날짜: `YYYY-MM-DD` + 날짜 차이(정수), 웹은 `new Date(y, m-1, d)`, 시간은 벽시계 분 그대로.
- 하루 종일은 위 줄, 보호자만(기기 캘린더) 일정은 담지 않음(공유 화면에 안내), 보호자 함께는 "보호자 함께" 표시.
- 남은 일: 카톡·메시지에서 링크 전체가 하나로 눌리는지(`$`,`+` 포함) 기기 확인, App Store 개인정보 항목 확인(수집 없음 유지).
