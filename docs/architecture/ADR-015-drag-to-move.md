# ADR-015 — 캘린더 일정 끌어서 옮기기 (아이폰 캘린더처럼)

- **Status**: **Accepted / 구현 완료, 기기 확인 전** (2026-11-11) — 오너 "꾹 누르면 드래그해서 일정 옮길 수 있게, 아이폰처럼"; 범위 = 일간 + 주간(요일도), 반복 일정 = 놓을 때 물어보기
- **Source**: 디자인 캔버스(비공개) https://claude.ai/artifact/7378YLCUUr4pMf7SgDfybx — 보드 `DR1`–`DR3`

## Decision
1. **제스처**: 타임 블록을 **0.3초 누르면 들어올림**(살짝 커지고 그림자) → 끌기. 짧게 탭하면 지금처럼 상세. 끄는 동안 그리드 스크롤(세로·가로)은 멈춤.
2. **맞춤**: 세로 = **15분 단위**(하루 안으로 제한, 길이 유지). 끄는 블록의 시간 글자가 새 시간으로 바뀜. 주간(블록 모드, 4일 이하) = 옆으로 **하루 단위**(보이는 요일 안). 일간은 사람(열) 이동 없음. 주간 막대 모드(5–7일)·하루 종일·아이폰 캘린더(보호자만) 일정은 끌 수 없음.
3. **저장**:
   - 한 번만 있는 일정 → 바로 옮김(날짜가 바뀌면 그 날짜·요일로).
   - 반복 일정 → 아이폰 기본 시트 "이 일정만 / 모든 일정 / 취소".
     - 이 일정만, 같은 날 → 그 회차 modify 예외(새 시간).
     - 이 일정만, 다른 날 → 그 회차 취소 + 새 날짜의 한 번짜리 복사본(함께하는 사람·보호자·알림·픽업·그날 보이던 준비물 포함). 예외 모델이 날짜 이동을 지원하지 않아서.
     - 모든 일정 → 기본 시간 이동, 다른 요일로 끌면 반복 요일 전체를 같은 날 수만큼 이동. (아이폰의 "앞으로"처럼 나누지 않음 — 지난 회차도 같이 바뀜)
   - 취소하면 블록이 제자리로 돌아감.
4. 함께하는 일정(ADR-013)은 어느 사람 열에서 끌어도 일정 하나가 옮겨짐.

## Not now
- 화면 끝으로 끌 때 자동 스크롤, 진동(expo-haptics = 새 네이티브 모듈), 길이 바꾸기(아래 끝 끌기).
